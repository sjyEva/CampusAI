# CampusAI 第一周实测报告

2026 年 11 月 25 日 · F 岗位 洪少敏 · 对应主分支 `02574248ab37e38eeacaf15bf81a8990fed9d8fa`

两个学生账号的课程隔离、发布后检索、逐条引用和原文件下载已在 H2、MySQL 两种后端上完成本机复验。学生端原始依赖清单存在一个安装缺陷，候选修正已经完成双平台编译。微信设备交互、六名成员的环境复验和正式双端业务联调保留为组内验收项。

## 实测环境

Windows；Java 17.0.16；Spring Boot 3.5.4；H2 2.3.232（内存库做 SQL 断言、文件库做重启）；MySQL Community Server 8.0.46（本机独立临时实例）；Node 24.15.0、npm 11.12.1。后端由 Maven Wrapper 从指定源码编译打包。HTTP 测试使用单独启动的 Java 进程与随机临时凭据。单元及集成测试中涉及模型响应的检查使用受控提供方；本轮实际 HTTP 进程关闭模型配置，未调用真实付费模型。

## 检索效果与测试校准

固定的 40 题沿用开发者原有语料及标注。本机运行后，30 道有依据题均在前三个片段中找到标注原文；10 道无依据题中 7 道正确返回空结果，3 道误召回，分别为最优页面置换、MC/DC 覆盖率计算、两阶段提交协调者故障。这组数字描述同一题集上 BM25 的检索表现；真实课程和模型回答质量需要另行评估。[本机逐题结果](运行记录/本机固定题集结果.md)

首次编写三格式用例时，DOCX 预期引文将“且”误录为“并”，断言按字面匹配失败。复查原 Word 表格第 8 段后，已更正测试脚本及样例说明，并从新建的 H2 和 MySQL 实例各完整重跑一次。上表记录两次最终执行结果。
