# F-01 学生端无法按主分支说明完成首次安装

**影响**　C 和验收成员使用干净工作目录时，标准安装在解析依赖阶段中止，无法继续构建 H5 与微信端。

**复现基线**　Git `0257424`，Windows，Node.js 24.15.0，npm 11.12.1。在干净副本 `student-miniapp` 下执行 `npm.cmd install`（验证时显式选择公共 npm registry）。npm 返回 `ERESOLVE unable to resolve dependency tree`。项目声明 `@dcloudio/types@3.4.8`，其锁定的 `@dcloudio/uni-app@3.0.0-5030420261029002` 的 peer dependency 指定 `@dcloudio/types@3.4.31`。

**候选修正**　仅将类型包改为 3.4.31，并保存该环境生成的 package-lock.json。修正在临时副本完成。补丁已通过对基线的 `git apply --check`；项目组可在独立分支复验。

**本机复测**　标准安装、按锁文件 `npm ci`、H5 构建、微信小程序构建均成功。H5 输出 `dist/build/h5/index.html`，微信端输出 `dist/build/mp-weixin/app.json`。仓库 manifest 中的 AppID 为空，构建器提示 uni 统计不可用。团队 AppID、微信登录和设备操作仍待 C 核对。

**交接给 C**　对照上一级《复现说明》，在自己的工作副本应用补丁、拷入锁文件，执行锁定安装及两个构建命令。完成微信开发者工具交互后，在任务卡填写测试设备、真实课程范围和复核结论。主分支合并状态由 A、C 处理。
