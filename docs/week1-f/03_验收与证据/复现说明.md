# 本机复验步骤

在 Windows 上使用 JDK 17、PowerShell 7、Python 3（HTTP 检查依赖 requests）和 MySQL 8 Server 的 bin 目录。管理端及学生端构建使用 Node 24、npm 11。先把下面的 `$repo` 改成自己的仓库目录。每个测试程序遇到断言错误时会返回非零退出码。

```powershell
$repo = 'D:\项目\CampusAI'
$qa = Join-Path $repo 'docs\week1-f\03_验收与证据'
$mysqlBin = 'C:\Program Files\MySQL\MySQL Server 8.0\bin'
$jar = Join-Path $repo 'backend\target\campusai-backend-0.1.0-SNAPSHOT.jar'
Set-Location -LiteralPath $repo
git rev-parse HEAD
.\backend\mvnw.cmd -B -ntp -f backend/pom.xml clean package
```

对照版本为 `02574248ab37e38eeacaf15bf81a8990fed9d8fa`。Maven 首次构建需联网下载依赖。测试套件包含开发者自编检索题集，以及使用受控模型服务的测试。若本机通过环境变量配置过真实模型，建议在没有个人模型配置的测试终端运行 Maven。下方 HTTP 程序会自行隔离个人配置。

## 数据库初始化

```powershell
$h2 = Join-Path $env:USERPROFILE '.m2\repository\com\h2database\h2\2.3.232\h2-2.3.232.jar'
$sqlDir = Join-Path (Split-Path $qa) '02_初始化与样例'
java -cp $h2 (Join-Path $qa 'VerifyH2.java') $sqlDir
python (Join-Path $qa 'verify_mysql.py') --bin $mysqlBin
```

如果 Maven 使用自定义本地仓库，把 `$h2` 改为实际的 H2 驱动路径。H2 用临时内存库；MySQL 验证器使用指定安装目录的程序，在新建临时目录初始化专用实例，通过本机随机端口连接。无需现有 MySQL 的账号，也无需启动 Windows 服务。两种脚本分别检查同一份 DDL、种子 SQL、计数、选课映射以及数据库约束。

## 后端、权限与来源

```powershell
python (Join-Path $qa 'verify_http.py') --repo $repo --jar $jar
python (Join-Path $qa 'verify_mysql.py') --bin $mysqlBin --repo $repo --jar $jar
```

第一条用文件 H2，第二条用临时 MySQL 和限定在测试库的应用账号。程序只向自己启动的回环地址发请求，未配置模型时检查 `retrieval_only` 及原文证据。先执行上游的 `scripts/verify-api.ps1` 和 `scripts/verify-rag.ps1`，再分别上传 PDF、DOCX、TXT，核对原文、定位、两种课程路径下的引用权限和原件字节；最后重启后端，复查持久化及会话失效。Python 依赖可在自己的虚拟环境通过 `python -m pip install requests` 安装。

## 管理端与学生端构建

管理端在仓库的 `admin-web` 目录依次执行 `npm.cmd ci`、`npm.cmd test`、`npm.cmd run build`。模块测试中的网络为可控的模拟请求，真实后端功能由上节的 HTTP 检查覆盖。

学生端缺陷 F-01 的原版复现步骤是在干净的 `student-miniapp` 目录执行 `npm.cmd install`。候选修正可在一份新的工作副本中复验。以下命令会修改该工作副本的清单和锁文件。

```powershell
Set-Location -LiteralPath $repo
$fix = Join-Path $qa '学生端依赖修正候选'
git apply --check (Join-Path $fix 'types-version.patch')
git apply (Join-Path $fix 'types-version.patch')
Copy-Item -LiteralPath (Join-Path $fix 'package-lock.json') -Destination 'student-miniapp'
Set-Location -LiteralPath 'student-miniapp'
npm.cmd ci
npm.cmd run build:h5
npm.cmd run build:mp-weixin
```

微信开发者工具或真机需要团队 AppID、可访问的测试后端和实际操作者。人工复验时分别用两个学生登录，打开自己的课程详情，确认另一个课程不可见，再切换账号检查上一名学生的课程是否仍显示。记录代码版本、设备、实际现象和日期。
